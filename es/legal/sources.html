FuenteLicencia y crédito

Las ocupaciones, los años, las titulaciones y los idiomas se leen con las reglas de Argus, un bot de búsqueda de empleo hecho para un ingeniero.

Los lugares se sitúan en el mapa con GeoNames (CC BY 4.0), y las ocupaciones se nombran con ESCO, © Unión Europea.

Solo se leen fuentes cuyas condiciones escritas permiten republicar: servicios públicos de empleo con licencias de datos abiertos, tableros de empresas en sistemas de selección con una API pública documentada, portales de empleo cuya API pide un enlace de vuelta, y las páginas de empleo de las propias empresas, leídas como las leen los buscadores (su mapa del sitio y el bloque JobPosting que publican para ellos), respetando robots.txt. Cada oferta enlaza a la página donde está: este sitio muestra su título, la empresa y el lugar, nunca el texto del anuncio. Para retirar una fuente o un anuncio, abre una incidencia; se atiende en 72 horas. Los anuncios que llegan por el programa de socios de un intermediario (Adzuna, Jooble, Talent.com, WhatJobs) van en una sección aparte, señalados, y enlazan a la página del intermediario como exigen esos programas; el sitio no les envía nada sobre ti.
